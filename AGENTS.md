# SuperTirititran · versión web

Aplicación estática con Phaser, TypeScript y Vite. Leer README.md antes de modificarla.

- Mantener las tres fases, presentaciones, Intercom, cuatro poderes, periódicos, cómic final y créditos.
- Conservar nombres y contenido de los originales de assets/. Generar derivados solo en public/assets/ y public/generated/.
- Mantener la carga progresiva de recursos por fase y el uso de audio original a demanda.
- Separar el terreno lógico del parallax visual y conservar las arenas fijas de los jefes.
- Usar rutas relativas compatibles con una subcarpeta de GitHub Pages.
- Mantener el guardado local; no introducir medición, credenciales ni datos de cuentas.
- Validar con npm run build y npm test. Para cambios en escenas o carga, comprobar también la campaña, presentaciones y carga por fases en navegador.
